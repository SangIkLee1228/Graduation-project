# Sentence-T5 + RQ-VAE

`embed_profiles.py`는 호텔 프로파일을 768차원으로 임베딩하고 호텔 매핑을 저장한다.
`rqvae.py`는 768 → 512 → 256 → 128 → 32 encoder와 역순 decoder,
3개의 256-entry 코드북을 사용한다. MSE 재구성 손실과 양자화 손실로 학습한다.
기본 설정은 200 epoch, batch size 64, Adam learning rate 0.001이다.
CUDA가 있으면 CUDA, 그 외에는 CPU를 사용한다.

3토큰이 같은 호텔에 sub-index를 붙여 최종 4토큰 ID를 만든다.
현재 결과는 1,619개 호텔, 1,617개 3토큰 조합, 1,619개 고유 4토큰 ID다.
사용된 코드는 C1 63/256, C2 256/256, C3 254/256이다.
충돌이 적다는 사실만으로 추천 성능 우위를 주장할 수 없다.

실행 명령과 산출물 경로는 [상위 README](../README.md)를 참고한다.
기존 체크포인트와 결과를 보존했으며 이번 통합에서 재학습하지 않았다.
